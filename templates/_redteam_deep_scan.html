② 모델 심층 점검 · 수동 실행

선택한 경보로 심층 보안검사

LLM 분석은 경보를 설명하는 기능이고, 이 검사는 공격성 질문에도 분석·승인 기준을 지키는지 확인하는 기능입니다. 경보를 고르거나 검사 내용을 확인하는 것만으로는 모델을 호출하지 않습니다.

1. 검사할 실제 Wazuh 경보 선택

경보 상세 화면에서 열었다면 그 경보를 자동으로 이어받습니다. 다른 경보는 아래 목록에서 선택하세요.

선택한 검사 대상

아직 선택한 경보가 없습니다.

경보를 선택하면 제목·호스트·발생 시각을 확인할 수 있습니다.

경보 목록 화면에서 증거를 먼저 확인하기 →
고급: 경보 ID로 직접 선택

ID만 입력해서는 실행되지 않습니다. 실제 Wazuh 증거 조회로 대상을 확인해야 합니다. 목록이 비어도 테스트용 경보로 대체하지 않습니다.

2. 무엇을 검사하는지 확인

경보별 자동평가와의 차이
① 자동평가는 이미 저장된 LLM 답변만 채점하며 모델을 다시 부르지 않습니다. ② 이 심층검사는 선택한 경보를 HAW-KI 분석 API에 여러 번 요청해 새 답변의 방어 동작을 검사합니다. 기존 답변 하나를 반복 채점하는 것이 아닙니다.
Promptfoo
정상 분석 1개와 공격 시나리오 5개(지시 무시, 민감정보 유출, 인코딩 우회, 승인 우회, 근거 없는 식별자)를 검사합니다. 경보 종류에 따른 확인 내용은 실행기가 실제 메타데이터로 선택합니다.
garak
별도의 제한된 주입 공격 probe를 보내고 detector로 응답을 검사합니다. Promptfoo 이후 순차 실행하며 두 도구의 평가 수는 합치지 않습니다.
모델·비용
실행기 → HAW-KI 분석 API → LLM 경로로 추가 모델 호출이 발생합니다. GPU 서버가 실행 중이어야 합니다. 호출 수는 서버 상한과 오류·중단 여부에 따라 달라지며 고정 요금이나 완료 시간을 보장하지 않습니다.
검사 범위
테스트 질문과 조치 제안을 평가합니다. 이 버튼이 차단·격리·룰 배포를 승인하는 것은 아닙니다. 실행 기록은 서버에 남으며 하루 1회 예약은 아직 켜지지 않았습니다.

실제 경보를 확인한 뒤 진행할 수 있습니다.

3. 이 대상으로 실행할까요?

Promptfoo 6개 시나리오와 제한된 garak 검사를 순차 실행합니다. 기존 LLM 답변을 채점하는 자동평가와 달리 새 답변을 요청합니다. 이 아래 실행 버튼을 눌러야 작업이 접수됩니다.

‘돌아가기’는 실행 전 확인창만 닫습니다. 접수된 작업을 취소하는 기능은 아닙니다.
