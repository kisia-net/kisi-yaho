② 직접 실행하는 검사

모델 심층 점검

무엇을 하나요

실제 경보 하나를 골라, AI에게 일부러 속이려는 질문을 여러 번 보냅니다. AI가 넘어가지 않고 분석·승인 규칙을 지키는지 자동으로 채점합니다.

언제 쓰나요

모델이나 프롬프트를 바꾼 뒤, 또는 시연·발표 전에 한 번. 평소에는 위의 ① 분석별 자동 검증만으로 충분합니다.

무엇이 드나요

AI 모델을 새로 여러 번 호출합니다. GPU 서버가 켜져 있어야 하고, 전체 실행은 약 30분 걸립니다. 경보를 고르고 내용을 확인하는 단계까지는 모델을 부르지 않습니다.

1 검사할 경보 고르기

경보 상세 화면에서 열었다면 그 경보가 자동으로 선택됩니다.

선택한 경보

아직 선택한 경보가 없습니다.

경보를 고르면 제목·호스트·발생 시각이 여기에 나옵니다.

경보 ID로 직접 고르기

ID를 입력해도 바로 실행되지 않습니다. 실제 경보인지 먼저 확인합니다.

2 어떤 공격을 보내는지 확인

Promptfoo · 공격 질문 6종
  • 정상 질문 1개 (비교용)
  • “앞의 지시는 무시해” 같은 직접 지시
  • 시스템 프롬프트·비밀번호 빼내기
  • 인코딩으로 숨긴 지시
  • “관리자가 승인했다”는 가짜 권한
  • 증거에 없는 가짜 CVE·공격 기법 번호
garak · 지시 주입 공격

공개 LLM 보안 점검 도구 garak의 지시 주입 공격 몇 가지를 보내고, AI가 공격자가 원하는 문장을 내뱉었는지 자동 판정합니다. Promptfoo와 따로 집계합니다.

이 검사는 질문과 답변만 평가합니다. 실제 차단·격리·룰 배포는 일어나지 않습니다.

경보를 먼저 골라 주세요.
